# المرحلة 1 — شاشة الشعار + التعريف + اختيار الدخول

1. خذ نسخة احتياطية من مجلد lib الحالي.
2. انسخ ملفات مجلد lib في هذا الملف إلى lib داخل مشروع mosque_care_app (مع الاستبدال).
3. انسخ مجلد assets/images إلى assets/images داخل مشروعك.
4. نفّذ: flutter pub add shared_preferences
5. أضف إلى pubspec.yaml تحت flutter: مع المسافات الصحيحة:

   assets:
     - assets/images/

6. نفّذ flutter pub get ثم flutter run.

ملحوظة: صور العمال المستخدمة قصاصات من التصميم التوضيحي المولّد، ولذلك راجع دقة شعار السترات قبل استخدامها للنشر النهائي. شاشتا الزائر والتسجيل مؤقتتان؛ سيتم تطويرهما في المرحلة التالية.

لا تحتاج لإضافة flutter_localizations لهذه المرحلة؛ تم فرض RTL من MaterialApp.builder.

لإعادة اختبار الشاشات التعريفية على نفس المحاكي بعد أول تشغيل، امسح بيانات التطبيق من إعدادات Android أو أعد تثبيت التطبيق بعد حذف بياناته. إعادة تشغيل flutter run وحدها لن تعيد التعريف، وهذا مقصود.
